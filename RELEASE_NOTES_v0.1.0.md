# TPF3 Map Studio v0.1.0

First public release. / Erste öffentliche Version.

## English

A free Windows tool that prepares real-world map data for **Transport Fever 3**: heightmap, biome mask, towns, industries and a station list for the map editor import.

**Highlights**
- Heightmaps from DGM1 (Germany, 1 m), swissALTI3D (Switzerland/Liechtenstein, 2 m), Copernicus (worldwide, 30 m) or your own GeoTIFF tiles
- Height window for the editor limits (−20 to 3177 m) with preview: cap peaks, cut off lows or squash
- Water level suggestion, rivers from OSM, smoothing, levelling of routes and settlements
- The dialog lists the exact values to enter during the in-game import

**Install:** download `TPF3-Map-Studio-v0.1.0-win64.zip`, extract the **whole** ZIP, run `TPF3-Map-Studio.exe`. Windows may warn on first start ("More info" → "Run anyway"); antivirus false positives are known for PyInstaller programs.

**Note:** the program interface is German only for now. Unofficial tool, not affiliated with Urban Games.
