# TPF3 Map Studio v0.1.1

The program now speaks English. / Das Programm gibt es jetzt auch auf Englisch.

## English

**What's new**
- **English interface.** The whole program is available in German and English: menus, dialogs, messages, the map panel and the guides. On the first start it follows the Windows language. You can change it in the menu **Sprache / Language**; the change takes effect after a restart.
- The heightmap dialog now scrolls on small screens; the button bar stays at the bottom.
- Smaller download: unused languages and developer tools are no longer included.
- Standard buttons (Yes / No / Cancel) follow the chosen language.

**Install:** download `TPF3-Map-Studio-v0.1.1-win64.zip`, extract the **whole** ZIP, run `TPF3-Map-Studio.exe`. Windows may warn on first start ("More info" → "Run anyway"); antivirus false positives are known for PyInstaller programs.

**Note:** unofficial tool, not affiliated with Urban Games. The English game terms used in the interface (for example for the import in the map editor) are being checked against the English game; please report anything that does not match.

SHA-256: `d4690e1ad398722deea4fad26d1ee85584bada5bf2b14bcf1ae278f6c9c39d6e`
